The technical documentation (architecture, database, configuration, API reference and runbooks) is a separate site: {{ docs_url }}.

That site only answers while its server is running. If the link shows an error, start it first: open the control panel at {{ control_panel_url }} (on the PC that runs MediaCat), go to Docs server and click Start docs server. Starting the Docker stack from the control panel starts it too.
