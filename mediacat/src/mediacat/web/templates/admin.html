Discogs collection import

How collection import works

MediaCat can import your entire Discogs record collection automatically. Here is what you need to know:

  • Discogs username — your public Discogs profile name (visible in your Discogs URL, e.g. discogs.com/user/yourname).
  • Personal access token — required if your collection is private, or to avoid anonymous rate limits. Find it at discogs.com → Settings → Developers → Generate new token. The token is used only during the import and is never stored.
  • Existing pressings are skipped — any release already in MediaCat (matched by Discogs release ID) will not be re-imported. You can safely restart or resume.
  • Rate limiting — import runs at ~40 requests/min to stay well within Discogs limits. A collection of 200 albums takes roughly 15–20 minutes, including image downloads.
  • Pause & resume — you can pause the import at any point. It resumes from the last completed page, so no progress is lost.

Backup & Restore

{# Export #}

Export

Downloads a ZIP archive containing JSON exports of all catalogue tables: pressings, revisions, price history, images, artists, labels, and users. The file is saved to your browser's default download location.

Includes: tokens, revisions, images, price history, symbols, labels, manufacturers, users, review items.

⬇ Download backup
{# Import #}

Restore

Upload a MediaCat backup ZIP to restore catalogue data. Existing records with the same ID are skipped (safe to re-import). Images stored in MinIO are not included in the backup — only their metadata.

Caution: Restore adds rows — it does not wipe existing data first. To replace everything, clear the database manually before restoring.
